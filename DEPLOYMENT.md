# Deployment Guide

This project is structured as a monorepo with a React frontend (`client`) and a Node.js/Express backend (`server`).

## 1. Backend (Render)

The backend is configured for deployment on [Render](https://render.com/).

### Steps:
1.  **Create a New Blueprint:**
    -   Log in to Render.
    -   Click **New+** -> **Blueprint**.
    -   Connect your GitHub repository.
    -   Render will automatically detect the `render.yaml` file.
2.  **Configure Environment Variables:**
    -   In the Render dashboard, go to your service's **Environment** tab.
    -   Ensure the following variables are set:
        -   `MONGODB_URI`: Your MongoDB Atlas connection string.
        -   `NIM_API_KEY`: Your NVIDIA NIM API key.
        -   `GEMINI_API_KEY`: Your Google Gemini API key.
        -   `GOOGLE_CLIENT_ID`: Your Google OAuth Client ID.
        -   `JWT_ACCESS_SECRET`: (Auto-generated by blueprint, or set manually).
        -   `JWT_REFRESH_SECRET`: (Auto-generated by blueprint, or set manually).

## 2. Frontend (Vercel)

The frontend is configured for deployment on [Vercel](https://vercel.com/).

### Steps:
1.  **Import Project:**
    -   Log in to Vercel.
    -   Click **Add New...** -> **Project**.
    -   Connect your GitHub repository.
2.  **Project Settings:**
    -   **Framework Preset:** Vite.
    -   **Root Directory:** `client`.
    -   **Build Command:** `npm run build`.
    -   **Output Directory:** `dist`.
3.  **Environment Variables:**
    -   Set `VITE_API_BASE_URL` to the URL of your Render backend (e.g., `https://learnai-backend.onrender.com`).
4.  **Deploy:**
    -   Click **Deploy**.

## 3. Important Considerations

-   **CORS:** The backend is configured to allow all origins by default (`app.use(cors())`). In a production environment, you should restrict this to your Vercel domain for better security.
-   **Database:** Ensure your MongoDB Atlas cluster allows connections from Render's IP addresses (or allow access from anywhere `0.0.0.0/0` if necessary).
-   **Secrets:** Never commit `.env` files. Always use the platform's secret management tools.
